# 엔지니어 포트폴리오 수정본

기존 7쪽 PDF의 HTML/CSS 원본을 보존해 만든 8쪽 수정본입니다.

## 반영 내용

- 4쪽: 수충격 해석 및 기술보고서 작성
- 5쪽: 수충격 업무 중 반복된 CAD 종단면도 정리 자동화
- 7쪽: 플로우테크와 리팩의 참여 프로젝트
- 8쪽: 기존 경력·학력·기술 페이지

플로우테크 프로젝트 수는 `(2026)0616해석진행업무리스트.xlsx`의 `2025-057`부터 `2026-035`까지를 확인해 44건으로 정리했습니다. 포트폴리오에는 개별 프로젝트 코드를 넣지 않았고, 완료 여부가 확인되지 않는 항목이 있어 `44건 완료`가 아니라 `44개 프로젝트 참여`로 표현했습니다. 업체명 열은 `주요 협업사`로 구분했습니다.

리팩 참여 이력은 사용자가 제공한 고객사 목록과 직접 수행 범위인 기계 조립, 부품 가공·용접, 유압·기본 전기배선, 시운전·작동 확인을 기준으로 작성했습니다.

## 생성

`render.js`를 Playwright와 Sharp가 설치된 Node.js 환경에서 실행합니다. Google Chrome 기본 설치 경로를 사용하며, 다른 경로는 `CHROME_PATH` 환경 변수로 지정할 수 있습니다.

최종 PDF는 `output/pdf/정채민_엔지니어_포트폴리오_수정본.pdf`에 생성되고, 페이지별 검사용 PNG와 미리보기는 `tmp/pdfs/portfolio-preview/`에 생성됩니다.
