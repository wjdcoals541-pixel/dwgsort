# 국문 이력서 산출물

- 최종 Word 파일: `정채민_국문이력서_2026.docx`
- 연봉 포함 Word 파일: `정채민_국문이력서_2026_연봉포함.docx`
- 생성 스크립트: `../../scripts/build_korean_resume.py`
- 연봉 포함본 생성 스크립트: `../../scripts/add_salary_to_resume.py`
- 기준 자료: 2026-08-16자 AI 마스터 프로필 PDF와 사용자 제공 증명사진

## 구성 원칙

- A4 2쪽의 범용 기술직 지원용 국문 이력서로 구성했습니다.
- 경력, 학력, 직무 기술, 군복무, 운전면허 등 지원에 필요한 사실만 반영했습니다.
- 원문 PDF의 AI 지시문, 임금·법적 분쟁, 프로그램 소유권, 비직무 개인 맥락은 제외했습니다.
- `31건 이상`과 `하루 이상에서 약 10분` 성과는 수행 범위가 과장되지 않도록 표현했습니다.

## 검증

- 생성 스크립트 문법 검사 및 자체 내용 검증 통과
- A4 문서 구조, 고정 DXA 표 너비, 실제 Word 글머리표, 사진 임베드와 대체 텍스트 확인
- Microsoft Word 2021 PDF 내보내기 기준 2쪽 렌더링 및 전 페이지 시각 검수 완료
- 연봉 포함본은 경력 요약표에 `연봉(만원)` 열을 추가하고 플로우테크 3,400, 리팩 3,800, 엘리비젼 3,400을 반영했습니다.
